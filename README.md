The brief: roast a smart fridge (or any smart home gadget you live with) in a single line of at most 160 characters. The judge weighs the laugh first and the freshness of the angle second, so stock jokes about a fridge ordering too much milk lose to an angle nobody has heard before. Fourteen hand-written candidates were scored on humour, freshness, gadget-specific behaviour, and one-line punch; the strongest one won, then got a second revision pass that tightened its rhythm. `main.py` re-picks that winner deterministically, checks it against the 1–160 character single-line gate, and drops it into `/output/entry.txt`.

The winning line:

> My fridge now charges a monthly fee to stay cold — I'm paying rent to a box that judges my leftovers.

## How to run

```bash
python3 ./main.py
```

That prints the winner's score and character count and leaves the entry at `/output/entry.txt`.
